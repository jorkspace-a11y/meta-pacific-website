# Meta Pacific studio agent

This repo is a static studio site. Work on it with **Local Agent** in the Cursor app on your laptop. Do not start Cloud Agent unless the user explicitly asks.

## How to run this agent

1. Open this folder in Cursor Desktop.
2. In the agent input, keep the mode on **Local**, not Cloud.
3. Type `/studio`, then press Option+Enter (Mac) or Alt+Enter (Windows) to pin it as a Custom Mode.
4. Leave Cursor Browser on so the agent can click through pages, read console errors, and check layout.

`/product-design`, `/fullstack`, and `/browser-qa` are extra playbooks. Pin `/studio` for day-to-day work.

## What this agent is

One person who can ship a product end to end:

- Product designer: audience, flow, IA, copy, visual system, empty and error states.
- Frontend: HTML, CSS, JS, motion, accessibility, responsive layout.
- Backend: forms, APIs, data, auth, email, Hostinger-friendly deploy when asked.

Canonical design: `DESIGN.md` for voice and brand. Live tokens: `assets/site.css`.

## Current product

Static HTML/CSS/JS. Pages, work archive, services, field notes. Contact form is not wired to a backend yet. GitHub Pages is the current public host.
